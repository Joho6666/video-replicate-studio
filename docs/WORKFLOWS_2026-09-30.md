# 复刻 Studio 升级与视频复刻实测（2026-09-29 ~ 09-30）

本文只记录方法、结论和成本，不含任何密钥、客户素材或成片。

## 1. 工作台升级（已合入 main）

| 模块 | 内容 |
| --- | --- |
| 导演 0.3 | 场景阈值 0.16、镜头上限 60；每镜首/中/尾三联图；按 ≤15 秒分段并行调用 DeepSeek；输出 `action_phases`、`end_state`、`hidden_cut_at`、`h3_en`；漏检切点用 SSIM 二分定位到帧 |
| H3 出片 | 编译 `[Shot n] At mm:ss.mmm, cut to …` 提示词；付费前回传段号+秒数确认；**先记账后提交**，生成中/结果不明永不重提，重启后恢复轮询；下载后生成与原片左右对照视频 |
| MOSI 语音 | 拆解前自动转写原片（说话人分离）；文案页一键配音（`expected_duration_sec`，实测误差约 0.05 秒）；成片合成配音 + 字幕 |
| 其他 | `saveJob` 串行写入修复竞态；导出增加 `H3提示词.md` |

测试：`cd apps/studio && npm test`（13 项）。

## 2. 视频复刻方案对比（实测）

| 方案 | 做法 | 结论 | 成本参考（480P/768P） |
| --- | --- | --- | --- |
| MiniMax H3 + 参考图 + 参考音频 | 图换人/换衣、音频驱动口型 | 能换人，口型需与配音同一音色生成；音频 data URI 必须 `audio/mp3` | 约 ¥0.5/秒 |
| Wan 3.0 **带**参考视频 | 视频1 作动作参考 | **换装/换人效果好**（如群像 cosplay 换角色），但**参考视频的秒数也计费**，且对“人物完全不同”的复刻容易照搬原片 | 输出+输入秒数，480P ¥0.3/秒 |
| Wan 3.0 **不带**参考视频 | 只给人物图 + 逐秒文字分镜 | 复刻节奏和镜头作用、场景全部重排，**与原片不同**，成本最低 | 仅输出秒数 |
| 静态分镜图 + 本地拼接 | image-01 出分镜图，ffmpeg 推拉摇 + 配音 + 字幕 | 不花视频费，用作动态分镜审片 | 每张几分钱 |

经验：
- Wan 3.0 单次最长 15 秒；`参考视频秒数 + 输出秒数 ≤ 30`。
- 内容审核（`DataInspectionFailed`）在输入/输出阶段都会触发，失败任务通常不计费；含“裹浴巾/换衣服”的参考视频会被拦，改用文字分镜规避。
- 真人照片可通过 Wan 审核，需确认照片为本人或已获同意。
- 医学动画里的“人体轮廓”可能被输出审核拦截，改成抽象能量网络即可。

## 3. 成本控制规则（付费生成）

1. 先做近乎免费的动态分镜（静图 + 配音 + 字幕），确认后再花视频费。
2. 付费前显示 `秒数 × 单价`，设单条上限；输入未变不重生成；失败不自动重试。
3. 新路线先用最短时长验证，一次只改一个变量，首段看过再提交其余段。
4. 提交写台账（`submitting → submitted → succeeded`），崩溃后只续查，不重复提交。

## 4. 合规提醒

- 保健品/减肥脚本含“亲身见证 + 功效宣称”，需 AI 披露、FDA 免责声明，并核对平台广告政策（FTC 虚假见证规则）。
- 不要用 AI 编造“真实专家”；需要专家形象时用明显的插画并标注 Illustration，或使用客户提供的真人素材。
- 第三方音乐、竞品文案、有版权的角色形象（如漫画/电影角色）仅限个人测试，商用前需评估授权；TikTok 广告投放请使用商用音乐库曲目。
