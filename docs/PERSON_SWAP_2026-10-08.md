# 视频换人复刻实测（2026-10-07 ~ 10-08）

只记录方法、结论和成本；不含密钥、客户素材、原片或成片。

## 1. 两类模型，适用面不同

| | 姿态驱动换人（`wan2.2-animate-mix`） | 生成式视频编辑（`wan2.7-videoedit`） |
| --- | --- | --- |
| 做法 | 按人体姿态逐帧驱动新人物，原片背景可保持 | 指令 + 最多 4 张参考图，直接改整段视频 |
| 要求 | 单人、正面、完整露脸、连续镜头；背影 / 特写 / 低头 / 快速剪辑会被拒（不收费） | 2–10 秒；不依赖正脸，背影和特写也能换 |
| 价格 | 标准 ¥0.6/秒，专业 ¥0.9/秒（只算输出秒数） | 720P ¥0.6/秒、1080P ¥1/秒，**输入和输出秒数都计费**，实际约 ¥1.2/秒（720P） |
| 已知问题 | 道具会丢（手里的食物 / 饮料）；多指（手部快速、透视缩短时）；背景被参考图带偏 | 切点处可能凭空编出别的镜头；嘴唇等纯特写可能丢；指令里写了不在该段的物品会被画进去 |

选型：能用 Animate 的镜头用 Animate（便宜，可抠图贴回原片背景）；被拒的镜头用 videoedit。按镜头切窗口，窗口里只放同一位主角的镜头，每次调用带同一组人物参考图。

## 2. 固定合成步骤（`scripts/swap-compose.mjs`）

RIFE 把 15 帧补到原片帧率 → RVM 视频抠图（新人物 ∪ 原人物）→ 只在这个区域用换人画面，其余每个像素都是原片自己的 → 可选 Real-ESRGAN + 颗粒。旧的"差异遮罩"会把模型重画过的背景带进来（背景偏离原片 5.5，新方法 0）。`--relight`（借原人物光影）实测不如不加，默认关。

## 3. 经验

- 参考图的背景会被带进画面；用原片的一帧改出同场景参考图（`qwen-image-edit-plus`）能保住背景和手里的道具，但近景正脸时编辑模型常保留原人物的脸，必须人工核对。
- 镜头切点检测会差一两帧：窗口多带前一个镜头的最后一帧，模型会在人物旁凭空画出残留物。用相邻帧差最大处定位切点。
- 让视觉模型数手指 = 瞎猜（14 张样本命中 7 张）；运动光流也看不出多指。目前的做法是缺陷库 + 人工复核拼图（`scripts/defects.mjs`、`scripts/swap-review.mjs`）。
- 付费：先写账本再提交；状态未知的任务绝不自动重提（探测脚本曾因此重复提交两次）；失败的校验（`InvalidVideo.*`）不收费。
