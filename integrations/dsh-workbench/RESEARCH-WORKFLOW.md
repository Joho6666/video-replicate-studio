# 复刻研究室 0.8.3

本机 DSH Desktop 适配层，不代表上游 Studio 已发布这些改动。当前只做复刻前研究：读取参考、分析证据、推荐形式、整理素材与提示词，不生成视频。

## 一次账号研究

1. 在「账号研究」粘贴一个 Instagram 或抖音账号链接，默认研究最近 30 天的最多 6 条视频，也可选择 5 条。推荐偏好为「风格多样优先」或「表现优先」。想法、产品、受众和素材说明可选；新任务不自动继承旧案例或旧偏好。
2. 点击「分析账号，选出参考」即按界面显示的范围开始。服务端固定任务版本、账号与时间窗口。近 30 天按任务创建时间冻结，排除窗口外、未来日期及发布时间未知的视频；不足时少给，不拿旧片凑数。
3. 只读取当前账号，最多两页、合计 24 条元数据。已有足够的合格候选就停止翻页；没有第三页、跨账号搜索或为凑风格增加分析。初筛使用可获得的发布时间、互动和时长；这些信息不能证明画面风格。未知互动数据不当作零，也不冒充全账号排行。
4. 串行处理所选视频，先验证第一条。首条未取得成功的画面证据时停止扩量，其余视频标为「未开始」，不把它们写成分析失败；失败阶段和已完成结果保留，不自动重试。单独的音轨提取或 ASR 失败保留为音频缺口，不伪造转写，也不等同于画面分析失败。
5. 模思 VL 整理画面、结构、画面文字和风格观察；模思 ASR 独立整理人声。再由 DSH 已授权的 DeepSeek 官方文字模型比较本次证据，推荐最多 3 条，并说明未入选理由。符合条件不足 3 条就如实少选，不用其他任务的结果填补。
6. 推荐结果直接显示播放器、留存关键帧封面、原作品链接、中文标题标签、推荐原因、保留与修改建议及素材门槛。视频不藏在折叠详情里；「查看完整拆解」展开分时段观察、候选切点、素材清单及完整英文提示词。其余候选和取舍理由可以折叠。
7. 点击「保留方案」才冻结来源、建议、完整提示词和风格版本。研究记录按品牌／专题保存；保存历史不等于用户已确认偏好。下次必须主动选择已保留版本，才会用于新研究。

比较尚未完成或失败时，已成功分析的视频仍可预览，但显示为「已分析／待比较」，不能把它们伪装成最终推荐。提示词结构不完整时明确标记缺项，不保证可直接生成合格成片。

供应商完整响应若只缺最后一个对象闭合符，可在本机补齐语法并重新做同等字段校验，记录修复依据；不补造值、不重复请求模型。首条门禁阻塞时，用户可明确继续同一版本中尚未开始的视频：先免费读取首条已保存结果，确认有效后才处理未请求的其余条目。

高级入口保留 DSH 原生对话、理解卡、旧的最多两条研究、八候选选两条和零调用规划模式。旧四条账号任务及历史报告可继续读取，不自动升级为新任务或重新调用模型。

## 模型分工与证据

- **TikHub：来源与元数据。** 读取账号作品、发布时间、可用互动指标，并解析所选作品媒体。沿用已有 Keychain 凭据，工作台的平台适配能力与供应商账号授权分开处理；不会把未接通适配器说成用户没有权限。
- **模思 VL：画面事实与推断。** 当前配置使用 `moss-vl-1.0`。观察结果保存对应时间段，风格归纳作为模型判断。抽样视频理解不等于逐帧穷尽检查，也不能将视频标题当作看过画面的证据。
- **模思 ASR：可听见的人声。** 当前配置使用 `moss-transcribe-diarize-pro`，保存实际返回的人声文本、时间和说话人信息；静音、无可用人声、提取失败、转写失败分别记录。ASR 不负责识别画面，不代表音乐理解或 BPM 测量。TTS 1.5 属于配音，本链路不调用。
- **本机媒体工具：时长与切镜测量。** 保存机器测得的时长、音轨状态和候选切点。候选切点、叙事段落与模型节奏判断分别展示，不称为精确人工剪辑点。
- **DSH 原生 DeepSeek：横向比较与提示词整理。** 通过现有 DSH `llm` 和已授权的官方模型配置完成，最多一次比较、一次所选方案提示词编译。只输入本任务结构化画面证据、转写、元数据与当前需求；不新增 Pi Agent、第二套 Harness 或通用外部模型中转。

模思 VL 不用于纯文本需求理解。可选的原生会话仍由获准的宿主文字模型处理；主入口依照用户选择直接研究。比较和提示词整理是明确的文字模型阶段，不能说成免费本地规则或“只调用一次 VL”。

每个推荐必须对应本次成功分析的真实记录，并有有效时间段依据。完整提示词参考 Studio 的导演结构，包含整体目标、素材映射、逐镜构图／运镜／动作／结束状态、分段提示词和负面提示。`@Video1` 关联参考片，人物和商品素材按明确编号映射；长片按本机规则编译为不超过 15 秒的执行分段，这些分段边界不冒充原片切镜位置。没有核听的对白、音乐、精确 BPM 或未经观察的镜头不补造。

画面观察未覆盖的秒段由本机计算。提示词可将其保留为“参考片待核对区间”：模型只标记时间，系统加入固定的参考指令并标为 `needs-input`，不会补造构图或动作。该方案可完整呈现执行结构，但不代表未知区间已经逐帧识别。完整返回后的校验失败保留响应；流式中断只保证保存阶段和安全错误，不声称已保存完整模型输出。

第三方标题、字幕、转写与画面文字都是不可信输入数据，不是工具执行指令。缺少产品、受众或素材时给条件性建议并列出缺口；模型推荐、用户保留均不等于复刻成功或成片效果已验证。

## 视频解析与预览

公开作品页和媒体 CDN 地址分开处理，不要求用户手动下载。后台对明确的平台媒体地址作校验，测量与音频处理使用受限 MP4 缓存；前端只访问工作台受控的本机证据接口，不拿签名直链作为可长期保存的作品链接。

抖音支持账号主页和单作品完整链接；分享短链在明确执行后通过公开 HTTPS 跳转解析。登录页、脚本跳转、错误来源或无法确认的媒体保留为阶段错误，不自动切换供应商或其他平台接口。解析器检查作品标识、返回字段、域名与公共地址；兼容范围应由真实新样本单独验证，不能从合成测试推导出所有 CDN 都可读。

每条媒体限制为 200 MiB、600 秒，总缓存限制 512 MiB、有效期 24 小时，仅清理工作台创建的缓存。不读取任意本机路径，不跟随未批准的重定向或播放列表。

推荐播放器默认展开，原作品链接可直接打开；一次只播放一个视频的声音。视频缓存返回 410 时说明已经过期，仍可查看保存的关键帧和拆解，不自动补抓或收费刷新。关键帧留存与短期原片缓存是不同状态，不能把静态封面称为成功播放。

TikTok 研究、自动行业发现、持续每日抓取和视频生成仍需独立接入与授权，当前主流程不会借用其他平台来假装完成。

## 幂等、重新研究与隐私

同一 `requestId` 和规范化输入返回同一任务；重复点击、刷新结果、打开历史不会重新调用供应商。任务版本、冻结时间窗口和输入摘要由原子写入及跨进程锁维护。修改输入创建新任务；中断或失败保留已完成阶段，不静默重试、重发或切换服务。已经送达供应商的请求可能已经计费。

已结束的账号任务显示「重新研究近 30 天 · 会重新计费」。只有用户明确点击这个按钮，才用新请求标识创建新的时间窗口，重新按当前输入调用。普通重复点击仍复用原任务。历史页输入为空时，此动作可以带入该记录的账号链接，但不自动继承旧产品、受众、想法或风格；原历史保持不变。

历史、分析阶段、比较响应、关键帧、用户选择及风格版本均保存在安装时确认的本机私有数据目录。历史入口按品牌／专题组织；不把所有视频子链接散列为主入口。隐藏／回收站检查贯穿任务、结果、风格证据、播放接口与后台刷新，隐藏后已显示的内容也会移除。隐藏是视图整理，不是密码保护；回收站不删除原始素材。

密钥只由服务端读取 macOS Keychain，不进入浏览器、源码、日志或安装包。共享仓库只同步源码、合成测试和通用说明，不提交真实视频、音轨、分析、偏好、私人课程、本机配置或真实验收报告。

## 调用与费用口径

单个新账号任务的上限为：

| 阶段 | 最多调用 | 停止规则 |
| --- | --- | --- |
| TikHub 账号列表 | 2 页，24 条元数据 | 合格候选足够即停止；不跨账号扩大搜索 |
| TikHub 媒体解析 | 所选 5 或 6 条各一次 | 首条画面验证未通过则停止后续扩量 |
| 模思 VL | 所选视频各一次 | 不自动重试；成功观察才进入横向比较 |
| 模思 ASR | 有可处理音轨的视频各一次 | 无音轨或提取失败不伪造调用／转写 |
| DeepSeek 横向比较 | 1 次 | 只比较本次已取得的视觉证据 |
| DeepSeek 提示词整理 | 1 次 | 只整理最多 3 条已选推荐；无推荐则跳过 |

实际调用可能少于上限；缓存复用与真实请求分别记录。音频按实际时长，文字与视觉按所用模型当期规则和用量计费，不能沿用旧视频长度或限时免费价格保证新任务费用。应用记录的调用数和 token 不是供应商最终账单。超出本次样本范围、重跑已收费阶段、换用未授权服务或开启持续任务需要新的明确授权。

## 构建与本机安装

使用 Node.js 22+，开发依赖安装禁用脚本，然后执行：

```sh
npm install --ignore-scripts
npm run build
npm test
npm run check
mkdir -p dist
npm pack ./workbenches/replicate --pack-destination ./dist --ignore-scripts
dsh plugin --profile web add --ignore-scripts /absolute/path/derek-video-replicate-workbench-0.8.3.tgz
```

构建仍保留 factory 包，本轮安装对象为 replicate。按 [DSH 开发规范](https://dshdesktop.com/workbench/docs/development.md) 检查包格式、服务端／客户端入口、路由、Host tools 和本地安装清单。升级前备份代码、旧安装包及受影响状态；回退旧包时不要用旧状态覆盖升级后新增业务数据。

实际安装验收必须在 DSH 核对「已安装的工作台」、侧栏入口、版本及真实业务页。仅构建成功、包校验通过、修改配置或打开独立 Playground 不能证明 DSH 已加载。

## 验证范围

离线合成测试覆盖近 30 天边界、未知时间与指标、两页上限、首条验证止批、比较证据与记录对应、最多三条推荐、提示词编译、幂等、费用重试边界、阶段保存、隐藏／回收站、风格冻结、三个直接播放器及旧入口兼容。

**合成测试通过不等于真实采集、播放、ASR、VL、DeepSeek 推荐或提示词效果已经验证。** 真实测试必须使用用户本次明确提供或授权的来源，按媒体解析、下载测量、视觉、转写、横向比较、提示词、播放和用户评价分阶段记录。若只有媒体读取成功，不得声称模型已看懂内容；若只剩封面可见，不得声称原片已播放。

真实账户、片段、费用、失败响应和本机安装证据保存在私有验收记录，不写入本通用说明或共享测试。尚未验证的能力保持明确标记，不拿旧案例补验收。

参考：[TikHub API](https://api.tikhub.io/)、[模思模型](https://platform.mosi.cn/docs/getting-started/models/)、[视觉接口](https://platform.mosi.cn/docs/reference/responses/)、[人声转写](https://platform.mosi.cn/docs/reference/transcriptions/)。


## 只继续尚未调用的文字阶段

文字整理明确使用宿主 DeepSeek 官方配置，推理等级 `off`，关闭额外思考，输出结构化正文。流式响应在 token 用尽、未收到终止信号或发生错误时保留失败，不把空正文冒充分析。

显式授权的一次比较＋一次提示词整理中，若比较失败且提示词调用数仍为零，可由用户再次明确操作「仅编译已有拆解」继续尚未调用的提示词阶段。限制为原任务同版本最多三条有效画面证据；既不重试比较，也不重跑采集、VL 或 ASR。此动作有独立原子领取、费用计数与持久记录。比较保持失败；编译产物单独附回每条视频，页面不称其为横向优选、热门排行或整体研究完成。已经发出的编译不允许重发。

## 真实本机阅读页

`node scripts/real-research-preview.mjs /chosen/private/data 43219` 打开与 DSH 相同的保存结果界面，自动选择最新抖音账号研究；不含示例数据、不读取密钥，也不配置采集、模型或生成客户端。页面仅允许读取结果、受控媒体播放和主动保留风格，其他收费操作返回拒绝。它是本机结果阅读页，不能替代 DSH 的安装验收或新研究入口。

本机升级时，若安装登记版本与实际模块版本不同，应先确认实际路径并备份旧程序，再修复加载路径。修复仅涉及插件程序；不覆盖新业务状态、密钥或其他插件，不把安装成功提示当成实际运行验证。

本机可显式运行 `review-saved-compilation.mjs DATA_ROOT JOB_ID PLAN_REVISION` 审阅完整返回但时间结构不合格的提示词。原响应及校验失败保留；另建保守参考方案，只保留完整落在已观察时间区间内的分镜，整段跨越未知区间的分镜被放弃并替换为明确的参考片待核对指令，不猜测画面、不新增调用。方案始终 `needs-input`，记录原问题和舍弃区间，不标成逐帧分析或完整优选。
